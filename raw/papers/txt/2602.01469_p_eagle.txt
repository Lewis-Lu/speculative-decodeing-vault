A. Training configuration of ParallelSpec and PARD
All models are trained on 8 H200 GPUs with a global batch size of 64 and 8-step gradient accumulation. The target model is
GPT-OSS 120B. We use a linear learning-rate schedule with a peak learning rate of 1 × 10−4 and a warmup ratio of 0.0025.

B. Theoretical Justification for Redundancy of Hidden State Augmentation
We provide theoretical justification for why augmenting the shared hidden state—whether through prediction depth
embeddings or projected NTP context—is redundant. The key observation is that prediction depth g is a deterministic
function of sequence position p: in the MTP training structure, each position maps to exactly one prediction depth via g(p).
We prove that absolute position p can be uniquely recovered from RoPE-based attention scores. Since g(p) is computable
from p, introducing depth-dependent hidden states provides no additional information to the model.
Liu & Zhou (2025) prove that the mapping δ 7→ Rδ from relative position between a pair of query and key (q, k) ∈ Rd × Rd
to RoPE rotation matrix is injective, i.e., distinct relative positions always produce distinct rotation matrices. With a reference
token at known position (e.g., BOS at position 0), this implies absolute position is recoverable from the rotation matrix.
However, transformers do not observe rotation matrices directly; they compute scalar attention scores q⊤ Rδ k. The question
then arises: is the attention score mapping δ 7→ q⊤ Rδ k also injective? We prove that the set of query-key pairs for which
injectivity fails has Lebesgue measure zero.
Theorem B.1 (Liu & Zhou (2025)). The mapping δ 7→ Rδ from relative position to RoPE rotation matrix is injective, i.e.,
Rδ1 = Rδ2 =⇒ δ1 = δ2 .

measure zero in R2d .

a polynomial in 2d variables with the non-zero monomial Mi∗ j ∗ qi∗ kj ∗ . Since a non-zero polynomial defines a proper
algebraic hypersurface, its zero set has Lebesgue measure zero.

Theorem B.3 (Attention Score-Level Injectivity). The set of (q, k) ∈ Rd × Rd for which the attention score function
fq,k (δ) = q⊤ Rδ k fails to be injective in relative position δ has Lebesgue measure zero.

Proof. Let q, k ∈ Rd be query and key vectors, and consider any δ1 ̸= δ2 . By Theorem B.1, Rδ1 ̸= Rδ2 , thus M = Rδ1 −
Rδ2 ̸= 0. The condition fq,k (δ1 ) = fq,k (δ2 ) can be rewritten as q⊤ Rδ1 k = q⊤ Rδ2 k, or equivalently q⊤ (Rδ1 − Rδ2 )k =
q⊤ M k = 0. By Lemma B.2, since M ̸= 0, the set of (q, k) satisfying q⊤ M k = 0 has Lebesgue measure zero.

Corollary B.4 (Absolute Position Recovery). Let r be a reference position with key vector kr ∈ Rd , and let m be a query
position with query vector q ∈ Rd . The set of query vectors for which the attention score sm,r = q⊤ Rr−m kr fails to
uniquely determine m has Lebesgue measure zero.

Proof. Since r is fixed, distinct absolute positions m1 ̸= m2 correspond to distinct relative positions δ1 = r − m1 ̸=
r − m2 = δ2 . By Theorem B.3, the set of (q, kr ) for which the attention score function δ 7→ q⊤ Rδ kr fails to be injective
has Lebesgue measure zero. Therefore, sm1 ,r = q⊤ Rδ1 kr ̸= q⊤ Rδ2 kr = sm2 ,r except on a Lebesgue measure-zero set,
and absolute position m = r − δ is uniquely recoverable.

B.2. Hidden State Ablation Details
We evaluated five hidden state strategies for MTP positions. In PARD (An et al., 2025), prediction depth is referred to
as “group index” where group g ∈ {1, . . . , K} predicts the (g + 1)-th future token. We use the more descriptive term
“prediction depth” throughout.

   • Baseline (learnable shared): A single learnable vector hshared shared across all MTP positions. This is our recom-
     mended approach.
                                                                                                                                                                                                                    (g)                            (g)
   • + depth-specific encoding: Add a learnable embedding to differentiate prediction depth: hMTP = hshared + edepth ,
     where g ∈ {1, . . . , K} indicates predicting 1-step ahead, 2-steps ahead, etc. This is distinct from sequence position
     IDs (RoPE) used in attention.

   • + NTP hidden + depth encoding: Project the last NTP hidden state and combine with prediction depth embedding:
       (g)                           (g)
     hMTP = hshared + proj(hntp ) + edepth , where proj(·) is a linear layer. This provides both explicit context from the NTP
     position and prediction depth information.

   • + NTP hidden only: Project the last NTP hidden state without depth embedding: hMTP = hshared + proj(hntp ), injecting
     context while relying on attention for depth differentiation.

   • + regularized NTP hidden: Add projected NTP hidden state with dropout regularization and learnable scaling:
     hMTP = hshared + α · dropout(proj(hntp )). The scalar α is initialized to 0.1, allowing the model to start near baseline
     behavior (α ≈ 0 ignores context) and learn whether to increase α if context helps. Dropout (rate 0.1) prevents
     overfitting to specific context patterns.
